验证集按目标小时统计的方向准确率（活跃片区）。这是决定"今晚要不要按这张表派车"的依据。
怎么用：06:00 与 14:00 出两版清单。跨窗口看同一站点——3014 / 3042 早上缺、下午积压，3005 / 3030 正好相反，说明这批车一天能跑两趟，不需要增加车队规模。
边界：输出是「净流量（变化量）」，不是「库存」。要升级成真正的缺车报警，必须接入站点桩位容量与分时库存快照。
